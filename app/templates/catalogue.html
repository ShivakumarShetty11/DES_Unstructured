MCP Server Integration

Server URL

http://127.0.0.1:8000/mcp

Connect via Claude Code CLI

Run this once in your terminal — Claude Code will register the server and expose all tools in every session:

claude mcp add --transport http des-catalog http://127.0.0.1:8000/mcp

Or add to .claude/settings.json

Useful for project-level or team configs — paste into your project's .claude/settings.json:

{ "mcpServers": { "des-catalog": { "type": "http", "url": "http://127.0.0.1:8000/mcp" } } }

Available MCP Tools

tool list_datasets — all documents, metadata only
tool get_dataset(dataset_id) — full record incl. extracted_text
tool get_dataset_text(dataset_id) — extracted text only
tool search_datasets(query) — keyword search, metadata only
tool semantic_search_datasets(query) — vector similarity search
